## 02 / 我的构建方式

> **发现问题 → 拆解场景 → 协作构建 → 验证效果 → 持续迭代**

- **产品判断**：明确目标、使用场景与优先级。
- **协作构建**：结合算法、工程与 AI 工具，把想法推进到可体验的原型。
- **效果验证**：同时看体验、质量和成本，记录失败与取舍。

我喜欢能帮助讨论的原型，也喜欢能经得起追问的结论。
